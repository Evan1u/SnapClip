# SnapClip 品牌与界面规范

## 品牌定位

SnapClip 是一件常驻菜单栏的轻量截图工具。视觉关键词是：安静、精准、温暖、可信。品牌以一把圆润的拟物剪刀为核心：石墨刀刃、瓷白手柄、珊瑚转轴和暖白背景。界面保留“暗房工作台”的紧凑结构，但只迁移图标的材质配色与轻微层次，不复制厚重的 3D 质感。

## 颜色

### 品牌色

| Token | 色值 | 用途 |
|---|---|---|
| Pivot Coral | `#E96548` | 状态点、开关、文字操作与关键反馈 |
| Pivot Coral Strong | `#C84D36` | 错误、按下与高对比状态 |
| Blade Graphite | `#555452` | 截图入口悬停态与高权重中性色 |
| Blade Graphite Strong | `#363635` | 深按状态、深色背景与主文字 |
| Blade Highlight | `#6B6A67` | 深色模式抬升表面和边界 |
| Handle Porcelain | `#E9E6DF` | 浅色控件表面和深色主文字 |
| Handle Shadow | `#C8C4BC` | 次级文字和材料边界 |
| Studio Paper | `#F3F1ED` | 浅色窗口背景 |
| Studio Paper Raised | `#FCFBF8` | 浅色卡片和抬升表面 |

所有界面颜色只能来自以上九个基础色或它们的透明度变化。浅色模式以 Studio Paper 和 Porcelain 为底，深色模式以 Blade Graphite 为底；不再混用原有棕灰、系统蓝、系统橙或系统红。成功、提醒与错误通过图标形状和 Pivot Coral 的明暗变化共同区分。

**标注颜色例外**：截图编辑器里用户生成的图片内容（矩形/椭圆/直线/箭头/文字）不属于应用界面色，允许六种预设标注色（珊瑚、红、绿、蓝、白、石墨）和系统 `NSColorPanel` 任意 sRGB 颜色；选择框、旋转手柄等编辑辅助层使用白色/石墨透明度实现。编辑窗口采用暖石墨工作区，底部工具栏为悬浮抬升表面，所有界面层仍遵守九色系统。

**新截图 overlay**：新截图的冻结/选区/编辑层使用同一九色系统。冻结画面统一覆盖半透明暖石墨黑遮罩（透明度约 0.25–0.45），被框选/编辑区域恢复原亮度；选区与窗口高亮使用 Pivot Coral 或白色描边。overlay 编辑器不复制历史窗口的暖石墨工作区底色，画布透明，让冻结背景自然透出；工具栏仍是悬浮抬升表面并吸附在选区附近。历史卡片的独立编辑窗口继续遵守本节“编辑窗口”语义。

## 字体

- 展示字体：系统 Serif，仅用于 `SnapClip` 品牌标题，18–22 pt、Semibold/Bold。
- 正文字体：系统 Sans-serif，用于标题、按钮、正文和说明。
- 数据字体：系统 Monospaced，用于快捷键、历史容量和截图序号。
- 单个界面最多使用四个字号层级：18–22 pt 品牌标题、13–14 pt 分组标题、12–13 pt 正文、10–11 pt 元数据。

## 间距与形状

- 基础网格：8 pt；允许 4 pt 用于紧凑内部间距，12 pt 用于介于两级之间的组合。
- 菜单水平边距：16 pt；设置页水平边距：24 pt。
- 分组间距：16–24 pt；组内间距：8–12 pt。
- 小圆角：8 pt；中圆角：12 pt；窗口内容大圆角：16 pt。
- 所有主要点击目标不低于 44×44 pt；小按钮通过额外内容区域满足点击目标。

## 标志与图标

- App 图标使用圆润拟物剪刀：石墨刀刃、瓷白手柄、珊瑚转轴和暖白底色。
- 菜单栏图标使用同一剪刀轮廓的纯色 Template Image；由 macOS 根据菜单栏状态自动着色，手柄孔与转轴以负空间区分。
- 菜单栏图标固定为 16 pt 画布，视觉尺寸与 macOS 相邻状态图标保持一致。
- 菜单和设置页首显示缩小的拟物剪刀品牌标记。
- 其余功能图标继续使用 SF Symbols，不使用 emoji 或来源不明的外部图标包。

## 布局方向

- 菜单栏弹窗像紧凑暗房工作台：顶部品牌与状态、双截图入口、历史接触印样列表、底部低权重操作。
- 双截图入口默认均为瓷白表面；指针悬停的入口切换为石墨刀刃色，并使用珊瑚细边强调，按下时再加深一级。历史卡片悬停时仅加深石墨边框并轻微抬升，不使用整块强调色填充。
- 顶部入口和历史卡片的悬停变化统一使用 120 ms ease-out；禁用项不出现悬停强调。
- 历史记录突出缩略图，并使用 `01 / 03` 一类等宽编号强化工作台感；不使用左侧强调色条。
- 每张历史卡片将元数据、操作按钮和异常反馈视为缩略图右侧的一个信息组，在该可用区域内水平与垂直居中，避免尾部形成无意义空白。
- 设置页使用清晰分区和稳定双列关系，快捷键录制控件保持原生可理解性。
- 浅色和深色模式保持同一信息层级；深色使用暖石墨而非纯黑。

## 每屏标志性细节

- 菜单：拟物剪刀品牌标记、随指针移动的石墨截图动作、珊瑚状态点，以及编号式历史元数据。
- 设置：品牌标记与简短隐私承诺组成的紧凑页首，底部本地处理说明与主要设置形成呼应。

## 禁止项

- 除菜单栏 Template Image 的透明遮罩外，界面不得引入九色系统之外的展示颜色；不使用霓虹色或 emoji 功能图标。
- 不使用带左侧彩色边框的通用卡片。
- 不用大面积品牌色填充多个区域；一个屏幕只有一个主要 Coral 色时刻。
- 不牺牲 macOS 原生键盘、辅助功能和状态语义来换取装饰。
