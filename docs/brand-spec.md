# SnapClip 品牌与界面规范

## 品牌定位

SnapClip 是一件常驻菜单栏的轻量截图工具。视觉关键词是：安静、精准、温暖、可信。界面采用“暗房工作台”的紧凑结构与图像优先层级，同时使用暖象牙、暖灰和珊瑚色，避免沉重的固定黑色主题。

## 颜色

### 品牌色

| Token | 色值 | 用途 |
|---|---|---|
| Coral | `#D56547` | 主截图按钮、关键状态、开关与选中态 |
| Coral Strong | `#B84F35` | 按下与高对比状态 |
| Coral Soft | `#F5DDD5` / `#593326` | 图标徽标与轻量强调背景 |

### 暖中性色

| Token | 浅色模式 | 深色模式 | 用途 |
|---|---|---|---|
| Background | `#F7F3EF` | `#211F1D` | 菜单与设置页背景 |
| Surface | `#FFFDFB` | `#2D2A27` | 历史项、设置分组、次级按钮 |
| Surface Raised | `#FFFFFF` | `#35302D` | 悬浮或重点表面 |
| Text Primary | `#28231F` | `#F4EFEB` | 主文字 |
| Text Secondary | `#746B65` | `#B4AAA4` | 说明、时间、状态 |
| Divider | `#E3DAD3` | `#443F3A` | 边界与分隔线 |

错误、警告和成功状态使用 macOS 系统语义色，避免品牌色承担错误含义。

## 字体

- 展示字体：系统 Serif，仅用于 `SnapClip` 品牌标题，18–22 pt、Semibold/Bold。
- 正文字体：系统 Sans-serif，用于标题、按钮、正文和说明。
- 数据字体：系统 Monospaced，用于快捷键、历史容量和截图序号。
- 单个界面最多使用四个字号层级：18–22 pt 品牌标题、13–14 pt 分组标题、12–13 pt 正文、10–11 pt 元数据。

## 间距与形状

- 基础网格：8 pt；允许 4 pt 用于紧凑内部间距，12 pt 用于介于两级之间的组合。
- 菜单水平边距：16 pt；设置页水平边距：24 pt。
- 分组间距：16–24 pt；组内间距：8–12 pt。
- 小圆角：8 pt；中圆角：12 pt；窗口内容大圆角：16 pt。
- 所有主要点击目标不低于 44×44 pt；小按钮通过额外内容区域满足点击目标。

## 标志与图标

- 品牌标记使用 SF Symbol `camera.viewfinder`，置于 Coral Soft 圆角方形中。
- 功能图标全部使用 SF Symbols；不使用 emoji、自制拟物图标或外部图标包。
- 图标默认使用单色或 hierarchical 渲染，品牌色只用于主要动作和少量状态。

## 布局方向

- 菜单栏弹窗像紧凑暗房工作台：顶部品牌与状态、双截图入口、历史接触印样列表、底部低权重操作。
- 双截图入口默认均为暖白/暖灰表面，指针悬停的入口成为当前唯一 Coral 强调动作；按下时再加深一级。历史卡片悬停时只加深 Coral 边框并轻微抬升表面，不使用整块强调色填充。
- 顶部入口和历史卡片的悬停变化统一使用 120 ms ease-out；禁用项不出现悬停强调。
- 历史记录突出缩略图，并使用 `01 / 03` 一类等宽编号强化工作台感；不使用左侧强调色条。
- 每张历史卡片将元数据、操作按钮和异常反馈视为缩略图右侧的一个信息组，在该可用区域内水平与垂直居中，避免尾部形成无意义空白。
- 设置页使用清晰分区和稳定双列关系，快捷键录制控件保持原生可理解性。
- 浅色和深色模式保持同一信息层级；深色使用暖石墨而非纯黑。

## 每屏标志性细节

- 菜单：带取景框标记、随指针移动的 Coral 截图动作，以及编号式历史元数据和同色系悬停轮廓。
- 设置：品牌标记与简短隐私承诺组成的紧凑页首，底部本地处理说明与主要设置形成呼应。

## 禁止项

- 不使用渐变、霓虹色、纯黑背景、emoji 功能图标。
- 不使用带左侧彩色边框的通用卡片。
- 不用大面积品牌色填充多个区域；一个屏幕只有一个主要 Coral 色时刻。
- 不牺牲 macOS 原生键盘、辅助功能和状态语义来换取装饰。
